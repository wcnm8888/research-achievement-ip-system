# Product Brief - 科研成果与知识产权管理系统

## 项目背景

研究院目前主要依靠人工 Excel 台账管理论文、专利、软件著作权等科研成果及知识产权。现状存在成果信息易遗漏、专利和软著费用逾期风险高、全院成果底数不清、统计汇总耗时、跨系统重复录入、附件和审批留痕不规范等问题。

院内已有人员管理、财务、文献库等系统，但数据相互独立。本项目目标是在不修改原有系统底层数据的前提下，建设一套科研成果与知识产权一体化全生命周期管理系统。

## 产品目标

- 替代人工 Excel 台账，统一管理论文、专利、软著、费用、审批、附件、检索、统计和审计。
- 建立成果登记、审核、费用预警、归档、查询、统计的闭环流程。
- 通过 RBAC、部门数据隔离、涉密数据授权访问和操作审计满足合规要求。
- 通过预警和提醒降低专利年费、软著维护、申报事项逾期风险。
- 通过标准看板支撑院级、部门级和个人级成果管理决策。
- 为 DOI、邮件、HR/SSO、财务、专利状态同步等外部接口预留可替换 adapter。

## 用户角色

| 角色 | 核心目标 | 数据边界 |
| --- | --- | --- |
| 科研人员 | 登记和维护本人成果，查看个人成果和提醒 | 仅本人名下成果和附件 |
| 科研秘书 | 审核本部门成果，管理部门费用和报表 | 所属部门成果、费用、附件和审批 |
| 部门管理员 | 维护部门基础数据，协助权限和资料核查 | 部门数据只读为主，配置权限有限 |
| 主管/院领导 | 查看全院统计、趋势和部门排行 | 全院汇总和授权范围内详情 |
| 涉密成果管理员 | 管理涉密论文、国防专利、涉密专利和涉密软著 | 涉密成果专项授权数据 |
| 内审/审计人员 | 查阅日志、台账、审批、费用凭证 | 只读归档数据和操作日志 |
| 系统管理员 | 配置权限、字典、提醒规则、接口、运维 | 全局配置权限，禁止随意篡改业务数据 |

## 一期范围

一期基础刚需版聚焦可落地的核心闭环：

- 成果登记：论文、专利、软著统一登记，保留类型专属字段、唯一性校验、密级、附件和状态。
- 基础审批流：科研人员提交 -> 部门科研秘书初审 -> 系统管理员归档。
- 权限与隔离：RBAC、部门数据隔离、涉密成果授权访问。
- 费用台账与预警：专利和软著费用记录、截止日期、缴费状态、凭证附件、30/15/7 天及逾期预警。
- 基础全文检索：标题、摘要、作者/发明人、DOI、申请号、登记号等字段检索，结果按权限过滤。
- 基础统计看板：年度趋势、成果类型分布、部门排行、专利状态、费用汇总。
- 操作审计日志：新增、修改、状态变更、审批、附件上传/下载、费用处理均留痕。
- 附件管理：附件版本、下载权限、密级控制、存储 adapter。
- 外部接口预留：DOI 自动补全和邮件通知先用 Mock/Adapter，保留失败降级和调用日志。

## 二期范围

二期全流程深化版延后实现：

- 成果转化全流程、收益分配、转化漏斗和后评估填报。
- 完整费用线上审批、财务系统深度对接、批量缴费单。
- 高级组合检索、自定义报表、定时报表推送、引文分析。
- 真实 HR/SSO、专利法律状态、邮件、短信、财务接口联调。
- 移动端完整体验、运维监控大盘、灾备演练、十万级真实压测。

## 第一版明确不做

- 不做完整移动端。
- 不做真实短信接口。
- 不做完整财务系统深度对接。
- 不做十万级数据真实压测。
- 不做复杂自定义报表引擎。
- 不做完整成果转化闭环。
- 不做复杂可视化审批流设计器。
- 不做真实 CNIPA、Scopus、Dimensions 等外部接口联调。
- 不做硬删除业务数据。

## 非功能目标

- 普通页面目标响应时间小于 2 秒，基础统计看板小于 3 秒。
- 基础检索在一期验证数据集下目标平均响应小于 1 秒。
- 支持 50 名用户并发的常规操作设计目标。
- 操作日志至少保留 5 年，且不提供删除入口。
- 数据库和附件访问均强制鉴权，禁止越权查看或下载。
- 备份、灾备和生产运维能力在一期先设计接口和策略，二期或部署阶段落地演练。

## 成功标准

- 科研人员可以登记论文、专利、软著并提交审批。
- 科研秘书可以在部门范围内审核成果并处理费用台账。
- 系统管理员可以归档成果、查看审计日志和维护基础配置。
- 不同角色只能访问授权范围内的数据；跨部门、涉密、附件下载均受控。
- 费用预警可生成提醒任务并支持站内通知；邮件通知 adapter 可 mock 演示。
- 搜索和看板返回的数据经过权限过滤。
- 所有核心写操作均产生审计日志。
