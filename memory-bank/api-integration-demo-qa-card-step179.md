# Step179 - 接口演示 Q&A 卡片

## 使用边界

面向明天演示问答。口径必须保持为：

> 研究院科研成果与知识产权管理系统一期本地评审提交版 / local-demo / local Docker production-like。

不要说成真实生产上线完成版、真实外部系统联调完成版、VPS / 生产 DB 验收完成版。

## 快速开场

可以说：

> 本次 7.3 接口验收展示的是本地接口预留、Mock 预演、降级路径和安全调用日志。DOI 和邮件预演已经可演示，真实外部服务联调放在生产化接入阶段。

不要说：

> 所有外部接口已经真实接通，可以直接生产发送或同步。

## 现在 DOI 是否真实接入？

答：

> 还没有真实接入。当前是 DOI 自动补全预演，用本地 Mock 返回安全摘要，帮助登记人确认题名、作者、期刊、年份等字段。真实 Crossref / OpenAlex / Scopus / DOI 服务需要供应商凭据、网络和生产联调窗口。

补一句：

> 如果 DOI 预演失败，仍可手工录入，不影响成果登记。

避免说：

> DOI 数据实时来自 Crossref、OpenAlex 或 Scopus。

## 邮件是否真实发送？

答：

> 没有真实发送。当前是邮件通知预演，展示收件范围、主题、摘要、超时、重试和降级策略。页面明确不调用真实 SMTP、短信或企微。

补一句：

> 邮件通道不可用时，当前口径是站内提醒和人工跟进。

避免说：

> 邮件已经发出，或短信、企微已经接通。

## 接口失败怎么办？

答：

> 本地评审版已经把失败口径做清楚。DOI 失败时转手工录入。邮件失败时转站内提醒和人工跟进。HR、财务、专利等预留接口失败时转人工复核或延后同步。

补一句：

> 生产阶段还要补齐真实告警、失败重放、审计留存和值班升级。

避免说：

> 当前已经具备生产级自动重放和完整告警闭环。

## 为什么使用 Mock 预演？

答：

> 这次目标是本地评审提交版。Mock 预演能验证页面入口、配置开关、超时、重试摘要、降级路径和安全日志，不需要现场接触真实供应商凭证，也避免误发邮件或误同步数据。

补一句：

> 真实联调需要单独授权、供应商环境、密钥托管和验收窗口。

避免说：

> Mock 等同于真实外部接口验收。

## 上线前还差什么？

答：

> 还需要生产化接入专项。包括供应商账号和合同 SLA、密钥托管和轮换、网络出口和白名单、真实联调记录、监控告警、失败重放、审计留存、灰度回滚、生产演练和应急预案。

补一句：

> 当前版本的价值是把一期核心业务和接口预留边界做成可演示、可继续生产化的提交版。

避免说：

> 已经可以直接生产上线。

## 是否会泄露密钥或外发数据？

答：

> 本地演示不读取、不展示、不保存真实密钥、Token、Cookie、生产连接串或供应商凭证。接口日志只展示安全摘要，不保存外部原始请求和响应。

补一句：

> 演示现场也不在页面粘贴真实供应商凭证，不触发真实外发。

避免说：

> 可以现场输入真实 SMTP 密码或供应商 API Key 试一下。

## 是否支持后续接 HR / 财务 / 专利系统？

答：

> 支持作为后续接入方向。当前已在接口类型和 Mock 预演中预留 HR、财务、专利等场景，但还没有真实生产联调。后续需要按供应商、字段、权限、审计和失败处理逐项接入。

补一句：

> 存储和搜索也有预留类型，当前存储主要是本地磁盘和本地备份证据，不是对象存储生产验收。

避免说：

> HR、财务、专利系统已经真实打通。

## 当前版本可以怎么验收？

答：

> 可以验收本地一期可演示能力：成果登记 DOI 自动补全预演、系统配置页邮件通知预演、接口开关、超时、重试摘要、降级说明、安全调用日志，以及失败后手工录入、站内提醒、人工跟进等降级口径。

补一句：

> 不能把它验收为真实外部接口联调、生产上线、VPS / 生产 DB 验收或生产级监控告警完成。

## 7.3 一句话收口

> 7.3 当前补强的是本地评审版接口验收证据：DOI 和邮件预演可展示，接口配置和安全日志可展示，失败降级路径可说明；真实 DOI、邮件、短信、企微、HR、财务、专利、对象存储、告警、失败重放和审计留存仍属于二期 / 生产待接入。

## 禁止现场动作

- 不打开 `.env` 或 `.env.production`。
- 不展示密码、Cookie、Token、连接串或 API Key。
- 不访问 production / VPS / 生产 DB。
- 不调用真实 Crossref、OpenAlex、Scopus 或 DOI 服务。
- 不调用真实 SMTP、短信、企微、HR、财务、专利服务商。
- 不访问真实告警平台。
- 不触发真实邮件、短信或企微外发。
- 不把 Mock 结果说成真实外部系统联调完成。
