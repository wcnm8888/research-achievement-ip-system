# 项目需求完成矩阵（甲方视角版）

日期：2026-07-07

## 结论

从甲方验收视角看，当前项目**还不应冻结为生产交付版**。

可以成立的交付定义是：

> 科研成果与知识产权管理系统已经达到本地演示 / 竞赛评审 / synthetic 数据验证版。核心一期流程和多个增强切片可展示，但不等于生产上线、VPS 验收、生产数据库验收或真实外部系统联调完成。

如果甲方要求的是“生产系统完整上线”，则当前仍有生产身份、真实外部接口、真实财务、对象存储、运维监控、灾备、压测和移动端等缺口。

如果甲方要求的是“1 天内形成可评审的本地演示交付版”，则当前功能基础基本够用，重点已转为：

- 前端页面中文化、业务化、去开发痕迹。
- 需求覆盖和 caveat 讲清楚。
- 不把本地演示能力包装成生产验收。

## 当前前端展示状态

Step 134 已完成一轮 Web 甲方视角收口：

- 普通业务页面不再默认展示 `GET /...`、`POST /...`、`X-Demo-User-Id`、`Step xx`、`dryRun=true`、`local/demo`、`not production` 等开发/验收口径。
- `Custom Reports`、`Secret Authorization`、`Phase 1 frontend`、`production auth` 等已改为中文业务表达。
- 导入 `dry-run` 已改为 `导入预检` 表达。
- 涉密授权、自定义报表、导入记录、工作台、审批、检索、审计、看板、费用、账号、部门、系统配置等页面已做主路径文案清理。

仍建议做最后一次浏览器截图验收，确认真实运行页面与测试渲染一致。

## 明确延期或不声明完成

以下内容不得写成已完成：

- 生产上线、VPS 验收、生产 DB 验收。
- 生产 migration 执行。
- 真实 HR/SSO。
- 真实邮件、短信。
- 真实财务、付款、发票、对账、批量缴费单。
- 真实 DOI、文献库、专利平台、CNIPA、Scopus、Dimensions 联调。
- 真实对象存储、附件预览、附件加密落地、存储清理补偿。
- 完整 BI、自定义报表引擎、保存模板、定时报表推送、导出、引用分析。
- 涉密授权创建/撤销/审批/批量授权/导出/下载。
- 导入 retry、repair、rollback、delete、cleanup、raw CSV、raw JSON、导出或下载。
- 完整移动端体验。
- 生产监控、告警、备份恢复、灾备演练、十万级真实压测。
