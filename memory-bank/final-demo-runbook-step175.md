# Step175 - 最终现场演示 Runbook

## 定位

本 Runbook 面向“研究院科研成果与知识产权管理系统一期本地评审提交版 / local-demo / local Docker production-like”。

目标是在 7 分钟内稳定展示系统核心闭环，并在专家追问时保持准确边界：本地评审提交版已具备可演示能力，真实生产部署、真实外部系统联调、生产 DB/VPS 验收和正式大规模压测仍为生产化待接入。

## 推荐演示顺序

1. 打开工作台，先说明“本地评审提交版”定位。
2. 进入成果管理，展示成果台账和成果详情。
3. 打开成果登记，选择论文，展示 DOI 自动补全预演。
4. 进入提醒中心，展示待处理提醒、SLA 策略与扫描摘要。
5. 进入自定义报表，展示模板报表和定时报表预演。
6. 进入统计看板，展示引文影响力和部门/人员统计。
7. 进入审计日志，展示脱敏查询和导出记录。
8. 进入系统配置 / 接口预留，展示邮件通知预演和接口治理能力。
9. 最后用 Step174 矩阵口径收尾。

## 不建议现场点击

- 不点击真实外部系统接入、真实邮件发送、真实短信/企微、HR/SSO、财务、专利服务商。
- 不打开 `.env`、日志、Cookie、Token、密码、连接串、数据库控制台。
- 不运行生产部署、VPS、生产 DB、迁移、清理、删除、prune、reset。
- 不展示 `.local-step*`、性能日志、备份 SQL、截图临时产物或 PPT 临时文件。
- 不把 Mock / 预演 / 本地统计说成真实外部联调完成。

## 追问回答口径

### 问：是否已经可以生产上线？

答：

> 当前是一期本地评审提交版，核心业务链路、权限、审计、提醒、报表、接口预留已经形成可演示闭环。生产上线还需要部署、生产 DB、备份恢复、监控告警、外部系统联调和正式验收窗口。

### 问：DOI / 引文是不是实时来自 Crossref、OpenAlex 或 Scopus？

答：

> 当前演示版使用本地预演和本地派生统计，证明接口和页面闭环。真实 Crossref、OpenAlex、Scopus 或 DOI 服务联调需要凭据、对方服务和生产化接入窗口。

### 问：邮件是否真的发出去了？

答：

> 当前只生成邮件通知预演，展示接收范围、主题、摘要、超时、重试和降级策略，不调用真实 SMTP 或第三方邮件服务。

### 问：性能是否已完成生产压测？

答：

> 当前已有本地性能基线脚本，并支持认证参数。由于本轮未提供临时本地账号环境变量，认证后业务接口复跑尚未执行。不能宣称生产压测完成，正式性能验收需要生产类数据、压测窗口和监控基线。

### 问：备份恢复是否达到生产 RTO/RPO？

答：

> 当前完成的是本地 Docker production-like 的手动备份、manifest、SHA-256 校验和恢复 dry-run 计划。生产 RTO/RPO、每日备份、30 天留存和真实恢复演练需要生产环境专项验收。

## 最后 30 秒收口词

> 这版的目标不是伪装成生产上线，而是把一期评审需要看的核心链路做成可演示、边界清楚、可继续生产化的提交版。已完成部分包括成果登记、审批、费用提醒、报表、权限、审计、备份验收、接口预留和错误态稳定性；外部系统真实联调、生产部署、生产 DB、正式压测和生产备份恢复作为下一阶段专项推进。

## 现场异常处理

- 页面短暂加载：等待 3-5 秒，仍无结果则点击刷新或切换到相邻已验证页面。
- 出现无权限：说明当前账号权限边界生效，切换有权限业务用户。
- 出现服务不可用：不要展示错误细节，回到已加载页面继续讲业务闭环。
- DOI 或邮件预演失败：使用降级口径说明“保留手工录入 / 站内提醒 / 人工跟进路径”。
- 性能追问：按 Step174 口径说明脚本和认证变量边界，不现场输入或展示密码。

## 安全边界

- 不读取 `.env` / `.env.production`。
- 不展示账号密码、Cookie、Token、连接串、API Key、provider credential。
- 不访问 production/VPS/production DB。
- 不调用真实 DOI、文献库、SMTP、短信、企微、HR/SSO、财务或专利平台。
- 不删除文件或目录。
- 不处理或提交本地临时产物。
