# Step179 - 接口扩展与降级运维 Runbook

## 定位

本 Runbook 服务于“研究院科研成果与知识产权管理系统一期本地评审提交版 / local-demo / local Docker production-like”。

当前接口能力用于本地评审演示和生产化接入前说明。它不是真实生产上线完成版，不是真实外部系统联调完成版，也不是 VPS / 生产 DB 验收完成版。

## 本地演示环境接口边界

本地演示环境可以展示：

- 系统配置 / 接口预留页的接口列表、接口类型、启用状态、超时配置、配置引用、归档 / 恢复状态。
- Mock 预演中心的 DOI、邮件、HR、财务、专利场景。
- 成功、失败、降级三种预演结果。
- 安全调用日志摘要，包括接口编码、请求编号、状态、耗时、错误摘要和创建时间。
- DOI 失败后的手工录入路径。
- 邮件失败后的站内提醒 / 人工跟进路径。

本地演示环境不能宣称：

- 已接入真实 Crossref、OpenAlex、Scopus 或 DOI resolver。
- 已接入真实 SMTP、短信、企微或第三方邮件服务。
- 已接入真实 HR、财务、专利、对象存储或外部搜索服务。
- 已完成生产密钥托管、供应商 SLA、真实告警、失败重放或审计留存策略。

## DOI 自动补全预演操作口径

演示入口：

1. 进入成果登记或成果编辑页面。
2. 选择论文成果。
3. 在 DOI 字段填入本地演示 DOI。
4. 点击“自动补全预演”。
5. 展示返回的题名、作者、期刊 / 会议、发表年份、引用摘要和字段建议。

允许说明：

- 当前为本地预留接口预演。
- 预演结果用于辅助登记人手工确认。
- 预演不会自动覆盖用户已填内容。
- 预演不会写入真实外部请求或响应。
- DOI 通道失败时，仍可继续手工录入论文信息。

禁止说明：

- 不说已经实时接入 Crossref / OpenAlex / Scopus。
- 不说已经完成真实 DOI 联调。
- 不说引用数据来自真实外部文献库。
- 不展示或粘贴任何 DOI 供应商密钥、Token、Cookie 或生产连接串。

## 邮件通知预演操作口径

演示入口：

1. 进入系统配置 / 接口预留页。
2. 选择邮件接口类型。
3. 运行“邮件通知预演”。
4. 展示接收范围、主题、摘要、通道状态、重试策略、超时和降级路径。
5. 展示近期安全调用日志摘要。

允许说明：

- 当前只生成邮件通知预演。
- 邮件预演展示的是发送策略和降级路径。
- `sendsExternalMessage=false` 表示不会触发真实外发。
- 邮件失败时，可降级为站内提醒和人工跟进。
- 站内提醒是本地闭环能力，真实外部送达需生产接入。

禁止说明：

- 不说已经真实发送邮件。
- 不说已经接入真实 SMTP、短信、企微或第三方邮件服务。
- 不现场输入真实 SMTP 密码、API Key、短信签名密钥或企微凭证。
- 不把本地 stub delivery 或 Mock 预演当作真实送达回执。

## HR / 财务 / 专利 / 存储预留接口说明

| 接口领域 | 当前状态 | 本地可展示内容 | 降级路径 | 生产待接入 |
| --- | --- | --- | --- | --- |
| HR / SSO | Mock 预演 | `HR_SYNC` 人员变更摘要，不创建凭证或 SSO 会话 | 人工账号维护 | HR 主数据、SSO、组织同步、账号生命周期 |
| 财务 | Mock 预演 | `FINANCE_RECONCILE` 对账摘要，不创建付款、发票、收据或凭证 | 人工对账 | 财务系统、支付、发票、凭证、回执 |
| 专利 | Mock 预演 | `PATENT_STATUS_SYNC` 状态同步摘要，不同步官方专利数据 | 人工复核 | 专利服务商、官方状态、年费节点对账 |
| 存储 | 接口类型预留，本地磁盘能力已具备 | 附件上传、元数据、权限下载、部分预览、本地备份证据 | 本地文件和手工恢复流程 | 对象存储、预签名 URL、跨区备份、恢复演练 |
| 搜索 | 接口类型预留，本地数据库检索为主 | 本地检索页面和业务筛选 | 数据库检索 | 外部搜索引擎、索引同步、重建和监控 |

## 配置项说明

| 配置项 | 当前含义 | 本地演示口径 | 生产化要求 |
| --- | --- | --- | --- |
| provider | 接口类型，如 `DOI`、`EMAIL`、`HR`、`FINANCE`、`PATENT`、`STORAGE`、`SEARCH`、`OTHER` | 用于区分预留接口领域 | 需绑定真实供应商、账号、网络和责任人 |
| enabled | 接口开关 | 可展示启用 / 停用状态 | 需作为生产开关和降级控制点 |
| timeoutMs | 超时配置，默认 3000 ms | 展示超时策略字段 | 需结合供应商 SLA、网络耗时和重试策略确认 |
| retryPolicy | 当前主要在邮件预演结果中展示摘要 | 可说明“最多 2 次重试，失败后转站内提醒”等演示策略 | 需实现生产重试、幂等、限流和禁止重放规则 |
| configRef | 配置引用名 | 只展示引用，不展示密钥值 | 需指向密钥托管系统或受控配置项 |
| alertSummary | 告警摘要口径 | 可说明告警策略尚未接入真实平台 | 需接入真实告警渠道、阈值和值班升级 |
| fallback | 降级路径 | DOI 手工录入，邮件站内提醒 / 人工跟进，其他接口人工复核 | 需定义触发条件、责任人、恢复确认和审计记录 |

## 故障处理

| 故障类型 | 本地演示处理 | 现场说明 | 生产接入前要求 |
| --- | --- | --- | --- |
| 超时 | 预演返回失败或降级摘要 | “保留手工处理路径，不阻断业务登记” | 配置超时阈值、重试次数、熔断和告警 |
| 供应商不可用 | 不访问真实供应商，仅展示 Mock 失败 / 降级 | “真实供应商不可用时转人工或站内路径” | 供应商 SLA、状态页、应急联系人和切换预案 |
| 配置缺失 | 预演返回不可用或降级说明 | “缺少启用配置时不发起外部调用” | 上线前完成配置审批、密钥托管和只读验证 |
| 返回不完整 | DOI 预演保留人工确认字段 | “自动补全只做参考，不自动覆盖用户输入” | 字段映射、缺失字段策略、人工复核规则 |
| 权限不足 | 页面显示权限边界，不展示接口管理功能 | “系统配置能力受 `system:config` 控制” | 生产角色审批、最小权限和审计 |
| 安全日志为空 | 可说明本地尚未运行预演或未写入日志 | “日志只记录安全摘要” | 生产日志留存、检索、归档和脱敏策略 |

## 降级方案

- 手工录入：DOI 或文献库不可用时，登记人继续手工录入题名、作者、期刊、年份和摘要。
- 站内提醒：邮件外发不可用时，提醒中心保留站内提醒路径。
- 人工跟进：邮件、财务、HR、专利接口不可用时，由对应业务责任人线下确认。
- 延后同步：供应商服务恢复后，由生产运维按审批流程执行补偿同步，不能在本地评审版自动重放。
- 人工复核：返回不完整、字段冲突或供应商状态不确定时，保留人工确认再入库。

## 安全调用日志与脱敏边界

`ApiCallLog` 当前可见摘要：

- `integrationCode`
- `requestId`
- `status`
- `durationMs`
- `errorSummary`
- `createdAt`

脱敏边界：

- 不保存外部原始请求体。
- 不保存外部原始响应体。
- 不保存 Header、Cookie、Token、API Key、密码、私钥或生产连接串。
- 不保存真实供应商凭证。
- 不展示原始邮件正文、短信正文、企微 payload 或供应商错误全文。
- `errorSummary` 只记录安全摘要，不记录可反推出凭证或个人隐私的内容。

## 运维责任

| 阶段 | 责任人 | 需要确认 | 不做事项 |
| --- | --- | --- | --- |
| 本地评审版 | 演示负责人 / 项目负责人 | 页面可展示、Mock 预演可讲清边界、失败可降级说明 | 不输入真实凭证，不触发真实外发，不访问生产环境 |
| 生产接入前 | 项目负责人 / 运维 / 安全 / 业务接口负责人 | 供应商账号、合同 SLA、密钥托管、网络、告警、审计、失败重放和回滚方案 | 不绕过审批，不把本地 Mock 当作生产验收 |
| 生产运行期 | 运维 / 安全 / 业务值班人 | 监控指标、告警处置、密钥轮换、供应商 SLA、审计留存、人工补偿记录 | 不在页面粘贴密钥，不手工篡改生产数据，不无审批重放失败请求 |

## 不可操作项

- 不得粘贴密钥、Token、Cookie、密码、证书、私钥或生产连接串。
- 不得在页面输入真实供应商凭证。
- 不得现场触发真实邮件、短信、企微或其他外发。
- 不得访问 production / VPS / 生产 DB。
- 不得调用真实 DOI、Crossref、OpenAlex、Scopus、SMTP、HR、财务、专利或告警平台。
- 不得执行数据库写入、迁移、清理、删除、Docker prune 或 volume prune。
- 不得把 Mock 预演、站内提醒、本地安全日志说成真实外部系统联调完成。

## 演示收口话术

建议说：

> 当前 7.3 接口验收覆盖的是本地评审提交版的接口预留、Mock 预演、降级路径和安全日志摘要。DOI 自动补全和邮件通知预演已可演示，但真实 DOI / 文献库、SMTP / 短信 / 企微、HR、财务、专利和对象存储接入仍需生产化窗口、供应商凭据、密钥托管、SLA、告警、失败重放和审计留存专项验收。

避免说：

> 系统已经完成真实外部接口联调，已经完成生产上线，已经完成 VPS / 生产 DB 验收，或者已经可以直接使用真实供应商发送通知。
