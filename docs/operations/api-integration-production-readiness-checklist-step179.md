# Step179 - 外部接口生产接入前检查清单

## 定位

本清单用于后续生产化接入准备，不在 Step179 执行。当前项目定位仍是“研究院科研成果与知识产权管理系统一期本地评审提交版 / local-demo / local Docker production-like”。

本 Step 不执行真实外部接口调用，不修改生产配置，不读取真实凭证，不访问 production / VPS / 生产 DB。

## 使用方式

- 勾选项只能作为生产接入前准备清单。
- 每一项需有责任人、证据文件、审批记录或验收记录。
- 未完成项不得在评审中表述为“真实生产已完成”。
- 涉及密钥、Token、Cookie、连接串和供应商凭证时，只记录托管位置或配置引用，不记录明文。

- 不接真实 DOI、Crossref、OpenAlex、Scopus。

- 不访问真实告警平台。

- 不做 VPS / 生产 DB 验收。
- 不提交真实凭证或供应商配置。

## 验收口径

当前可验收：

- 文档是否清楚区分本地 Mock 预演和生产真实联调。
- 文档是否覆盖 DOI、邮件、HR、财务、专利、存储等接口边界。
- 文档是否明确生产接入前必须补齐的密钥、SLA、监控、告警、审计、失败重放和演练项。

当前不可验收：

- 真实供应商调用成功。
- 真实邮件 / 短信 / 企微送达。
- 真实生产监控告警。
- 真实生产审计留存。
- 真实生产上线和生产 DB 验收。
