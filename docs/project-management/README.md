# 项目管理文档

当前目录只保留下一阶段继续开发、审查和交接所需的轻量上下文。当前权威入口是：

- `roadmap.md`：项目级路线、阶段状态和路线边界；
- `current-task.md`：当前唯一任务；没有功能任务时明确写空；
- `implementation-plan.md`：当前阶段执行计划；
- `progress.md`：最近状态摘要；
- `evidence.md`：命令、结果、覆盖范围和风险摘要；
- `decisions.md`：当前仍有效的决策索引；
- `../overview/next-phase-options.md`：下一阶段选项。

Prompt 历史、完整终端输出、重复截图、原始浏览器痕迹和一次性构建产物不属于当前项目管理文档。

阶段一原始档案位于本机：

```text
E:\项目档案\研究院科研成果管理系统\阶段一-2026-07-09
```

历史文档中出现的 `阶段一档案/...` 均以该目录为根。原 `memory-bank` 中的长篇计划、进度、决策、证据和逐 Step 文档已保存到：

```text
阶段一档案/process-records/current-main-memory-bank/
```

提示词、验收原始产物、交付物和演示材料分别保存在阶段档案的同名分类目录。阶段档案只用于历史追溯和必要交接，不作为当前架构、需求、路线或任务的权威来源。
