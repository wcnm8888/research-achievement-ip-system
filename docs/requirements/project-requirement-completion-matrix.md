# 项目需求完成度矩阵

更新时间：2026-07-26

本矩阵以当前源码、测试和本地验收能力为准。完成度必须同时标明环境和边界，不能用“测试通过”替代生产验收。

## 状态定义

- **已实现：本地/demo/synthetic**：应用代码和测试已覆盖，主要证据来自本地或合成数据。
- **已实现但有边界**：主流程存在，但受身份、外部系统、数据规模或安全边界限制。
- **仅文档或 mock**：只有说明、接口边界或 fake/mock adapter，不能声称真实能力完成。
- **未实现**：当前代码没有足够实现或证据。
- **明确禁止声称完成**：即使有模型、脚本或本地演示，也不能当作生产完成。

## 必须明确区分的结论

- 本地 demo/synthetic 通过，不等于生产环境通过。
- mock adapter 通过，不等于真实外部系统可用。
- 单元、集成或验收脚本通过，不等于浏览器视觉验收完成。
- 文档或 runbook 存在，不等于流程已经执行。
- migration 文件或 Prisma Schema 存在，不等于生产 migration 已应用。
- 本地导入成功，不等于真实生产数据导入、校验和回滚完成。
- 账号生命周期 demo，不等于真实 HR/SSO 接入。
- 本地通知记录，不等于真实邮件/短信投递。
- 自定义报表 MVP，不等于完整 BI、导出和定时推送。

## 明确禁止声称完成的事项

当前不得声称生产部署、VPS 运维、生产数据库、真实身份、真实外部系统、生产数据迁移、灾备、大规模性能、完整移动端验收和完整合规审计已经完成。
